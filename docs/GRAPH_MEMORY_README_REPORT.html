让 Agent 的历史停止膨胀，但记忆继续生长。

Graph Memory 作为 DeepSeek Harness 原生插件，接管模型可见历史：保留最近轮次，归档旧工具轨迹，并在当前问题到来时召回相关原始问答与图谱关系。

不是删历史。是把历史从“负担”变成“可寻址记忆”。

DSH 的原始事件日志继续存在。Graph Memory 只接管送给模型的表面，并把完成轮次投影为问题、最终回答、类型化节点、关系和精确来源。

一个内核，两种原生接入。

作为插件安装，不修改 DSH。

npx @deepseek-ai/dsh plugin --profile web add github:adoresever/graph-memory
npx @deepseek-ai/dsh --profile web --dump-config
npx @deepseek-ai/dsh web
安装后检查在“设置 → 插件 → 插件列表”确认 graph-memory/dsh 为 active。Node.js 需要 22.13+；未配置 Embedding 时会使用 FTS5，不阻塞对话。
